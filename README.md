# Tedix-Text
Tedix-text is a Open source Mit Licensed IDE with plugin system.
Lightweight and easy to use

## Planned Features
Core (fileio, ui, pluginman, redo undo, ... read more at Core Features)
Plugin System
Syntax Highlighting
Project Manager
Fast Search Engine (with content search and filters)
plugins planned:
DevConsole -> Adds Console for developers
JDev -> Java Language Support
TedixPy -> Python Language Support

## Planned Core Features
Fileio
Custom UI
Plugin manager and plugin Core
redo and undo
Text Piece Buffer
